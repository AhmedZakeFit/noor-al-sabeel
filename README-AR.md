# نور السبيل — Noor Al-Sabeel

**مواقيت الصلاة والقبلة والمساجد القريبة لأندرويد — مجاني ومفتوح المصدر.**
بلا إعلانات. بلا اشتراكات. بلا حسابات. بلا تتبع.

**English:** [Read the documentation in English](README.md)

## الميزات

- **مواقيت الصلوات الخمس والشروق** مع عدّاد تنازلي للصلاة القادمة، إضافة إلى منتصف الليل
  والثلث الأخير.
- **طرق حساب متعددة** — رابطة العالم الإسلامي، الهيئة المصرية العامة للمساحة (الافتراضية)،
  ISNA، أم القرى (مع قاعدة العشاء في رمضان)، كراتشي، الخليج، الكويت، قطر، سنغافورة،
  تركيا، فرنسا، أو زوايا مخصصة بالكامل.
- **مواقيت المسجد المحلي** — أزح أي وقت بمقدار ±30 دقيقة لمطابقة مسجدك.
- **بوصلة القبلة** مع تصحيح الانحراف المغناطيسي وإرشادات المعايرة.
- **المساجد القريبة** على خريطة OpenStreetMap مع المسافة والاتجاه وزر ملاحة واحد يفتح
  أي تطبيق ملاحة مثبتة على جهازك.
- **إشعارات قابلة للتخصيص** — تفعيل لكل صلاة، تذكير قبل الصلاة، اختيار الصوت والاهتزاز،
  تنبيهات دقيقة، وزر تجربة.
- **أذان كامل (نداء صوتي)** — اختر رفع الأذان الكامل بدلًا من النغمة القصيرة؛ وللفجر
  أذانُه الخاص. التسجيل مضمّن في التطبيق ويعمل بلا إنترنت من أول تثبيت، ويُرفَع على مستوى
  صوت المنبّه مع إمكانية الإيقاف من الإشعار (انظر [NOTICE](NOTICE.md) لتسجيلات النطاق العام).
- **التقويم الهجري** (جدول أم القرى الرسمي 1924–2076) مع تعديل يدوي بالأيام لمطابقة
  الرؤية المحلية.
- **العربية (RTL) والإنجليزية (LTR)** من أول إصدار، بما يشمل الإشعارات والإعدادات، مع
  اختيار الأرقام العربية أو اللاتينية.
- **العمل دون إنترنت أولًا** — كل حسابات المواقيت والقبلة والتقويم تعمل محليًا، مع فهرس
  مدمج يضم نحو 4300 مدينة (2088 منها بأسمائها العربية) يعمل بلا إنترنت إطلاقًا.
- **الوضع الفاتح والداكن** حسب النظام أو يدويًا.

## التثبيت

نزّل أحدث APK موقّع من
[إصدارات GitHub](https://github.com/AhmedZakeFit/noor-al-sabeel/releases) وافتحه على هاتفك
(اسمح بالتثبيت من مصادر غير معروفة عند الطلب). لا حاجة لحساب Google Play.

> التقديم إلى F-Droid مخطط له لاحقًا (انظر [خطة المستقبل](docs/ROADMAP.md))، والقبول
> بيد فريق F-Droid وليس مضمونًا.

## الخصوصية

نور السبيل لا يجمع أي شيء: لا إعلانات ولا تحليلات ولا حسابات ولا متتبعات. كل الإعدادات
والمواقع تبقى على جهازك. يستخدم التطبيق الشبكة فقط عند فتح الخريطة أو البحث عن
المساجد أو البحث الاختياري عن المدن. التفاصيل الكاملة في
[سياسة الخصوصية](PRIVACY.md).

## الدقة والمصادر

تُحسب المواقيت على الجهاز بخوارزميات فلكية قياسية (Meeus — *Astronomical Algorithms*)
ويجري التحقق منها آليًا مقابل مراجع مستقلة. لا يمكن لأي حساب مواقيت أن يكون دقيقًا
بصورة مطلقة: زوايا الشفق والتقريب والعادات المحلية تُحدث فروقًا صغيرة، فراجع دائمًا
مسجدك. تعرف على كل طريقة ومصدر وحد معروف في
[docs/PRAYER_TIMES.md](docs/PRAYER_TIMES.md). بوصلة القبلة تعتمد على مستشعرات هاتفك
المغناطيسية — يعرض التطبيق دقتها ويرشدك للمعايرة، لكن بوصلات الهواتف لها حدود فيزيائية
حقيقية.

## ابنِ التطبيق بنفسك

```bash
git clone https://github.com/AhmedZakeFit/noor-al-sabeel.git
cd noor-al-sabeel
./gradlew :core:test :app:testDebugUnitTest   # تشغيل الاختبارات
./gradlew :app:assembleDebug                  # بناء الـ APK
```

تحتاج JDK 17 أو أحدث و Android SDK 35. التعليمات الكاملة مع توقيع الإصدارات عبر
متغيرات البيئة (بلا أي أسرار في المستودع) في [docs/BUILDING.md](docs/BUILDING.md).
