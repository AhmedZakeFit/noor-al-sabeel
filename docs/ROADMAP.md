# Roadmap — خطة المستقبل

Ideas are ordered roughly by value/effort. Nothing here is a promise; the project moves at
the speed of its contributors.

## Next (1.x)

- **Home-screen widget** with the next prayer and countdown (Jetpack Glance once the
  dependency situation is settled).
- **F-Droid submission** — prepare metadata and a reproducible build; acceptance is up to
  the F-Droid maintainers and is *not* guaranteed.
- **R8 shrinking + baseline profiles** for a smaller, faster APK.
- **More translations** (add string resources; the UI is already bidi-ready).

## Later

- Monthly/annual timetable view with export (calendar intent or plain table).
- Ramadan features: imsak line, suhoor/iftar reminders, 30-day countdown.
- Tasbih counter and a small set of authentic adhkar (with sources).
- Khatm tracking / reading goals (if kept local and small).
- Wear OS companion (tiles for next prayer).
- Instrumented UI tests running on CI emulators.

## Explicitly not planned

- Ads, subscriptions, accounts, analytics, or any form of tracking.
- Server-side computation for core features.
- Proprietary dependencies (Play services, Firebase, closed SDKs).
- Claims of perfect accuracy for prayer times or the compass.
