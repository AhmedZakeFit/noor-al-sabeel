# Support — الدعم

**English** | [العربية بالأسفل](#العربية)

## Where to go with what

| You have… | Where to go |
|---|---|
| A bug or something that does not work | [Open an issue](https://github.com/AhmedZakeFit/noor-al-sabeel/issues/new/choose) using the bug-report template |
| An idea for a feature | [Open an issue](https://github.com/AhmedZakeFit/noor-al-sabeel/issues/new/choose) using the feature-request template |
| A question, usage help, or general discussion | [GitHub Discussions](https://github.com/AhmedZakeFit/noor-al-sabeel/discussions) |
| A prayer-time discrepancy | Bug report — include city, method, date, and the two times (see [docs/PRAYER_TIMES.md](docs/PRAYER_TIMES.md) first) |
| A security vulnerability | **Privately** — follow [SECURITY.md](SECURITY.md), never the public tracker |
| A privacy question | [PRIVACY.md](PRIVACY.md), then the issue tracker if unanswered |

## Supported versions

Only the **latest release** receives fixes; older releases get no backports. Update in-app
(Settings → About → Check for updates) or grab the latest APK from
[Releases](https://github.com/AhmedZakeFit/noor-al-sabeel/releases). See [docs/ROADMAP.md](docs/ROADMAP.md)
for what is planned, and the issues labeled
[`good first issue`](https://github.com/AhmedZakeFit/noor-al-sabeel/labels/good%20first%20issue)
to start contributing.

## Expectations

This is a volunteer-run project: there is no SLA, no paid support and no guaranteed response
time, but issues and discussions are read and answered as time allows. Bug reports that follow
the template (version, device, Android version, steps) get useful answers much faster.

# العربية

## إلى أين تتوجه بحسب حالتك

| حالتك | وجهتك |
|---|---|
| خطأ أو أمر لا يعمل | [افتح مشكلة](https://github.com/AhmedZakeFit/noor-al-sabeel/issues/new/choose) بقالب تقرير الخطأ |
| فكرة ميزة جديدة | [افتح مشكلة](https://github.com/AhmedZakeFit/noor-al-sabeel/issues/new/choose) بقالب طلب الميزة |
| سؤال أو مساعدة في الاستخدام أو نقاش عام | [مناقشات GitHub](https://github.com/AhmedZakeFit/noor-al-sabeel/discussions) |
| فرق في مواقيت الصلاة | تقرير خطأ — أرفق المدينة والطريقة والتاريخ والوقتين (اطّلع أولًا على [docs/PRAYER_TIMES.md](docs/PRAYER_TIMES.md)) |
| ثغرة أمنية | **بسرية** — وفق [SECURITY.md](SECURITY.md)، وليس عبر المتتبع العام أبدًا |
| سؤال عن الخصوصية | [سياسة الخصوصية](PRIVACY.md)، ثم المتتبع إن لم تجد إجابتك |

## الإصدارات المدعومة

**أحدث إصدار فقط** يحصل على الإصلاحات دون إعادة نقلها للإصدارات الأقدم. حدّث من داخل
التطبيق (الإعدادات ← حول التطبيق ← التحقق من وجود تحديثات) أو نزّل أحدث APK من
[الإصدارات](https://github.com/AhmedZakeFit/noor-al-sabeel/releases). تعرف على المخطط في
[docs/ROADMAP.md](docs/ROADMAP.md)، وابدأ المساهمة من المشكلات الموسومة
[`good first issue`](https://github.com/AhmedZakeFit/noor-al-sabeel/labels/good%20first%20issue).

## التوقعات

هذا مشروع تطوعي: لا اتفاقية مستوى خدمة ولا دفع مقابل ولا زمن استجابة مضمون، لكن
المشكلات والمناقشات تُقرأ ويُجاب عنها بحسب الوقت المتاح. وتقارير الأخطاء الملتزمة
بالقالب (الإصدار والجهاز وإصدار أندرويد والخطوات) تحصل على إجابات مفيدة أسرع بكثير.
